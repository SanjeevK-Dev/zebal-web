ಮುಖ್ಯ ವಿಷಯಕ್ಕೆ ಹೋಗಿ
ಬಳಕೆದಾರರ ಗೈಡ್ / ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು ಬ್ಯಾಕಪ್

ಸೆಟ್ಟಿಂಗ್‌ಗಳು, ಬ್ಯಾಕಪ್ ಮತ್ತು ಆಕ್ಸೆಸಿಬಿಲಿಟಿ

ಆಪ್ ನಿಮಗೆ ಬೇಕಾದ ರೀತಿಯಲ್ಲಿ ಕೆಲಸ ಮಾಡುವಂತೆ ಮಾಡುವುದು — ಮತ್ತು ನಿಮ್ಮ ಡೇಟಾವನ್ನು ಸುರಕ್ಷಿತವಾಗಿ ಇಡುವುದು.

ಇಲ್ಲಿ ಇರುವುದೆಲ್ಲಾ ಮೇಲೆ ಬಲಭಾಗದಲ್ಲಿರುವ menu (three dots)ನಲ್ಲಿ ಇರುತ್ತದೆ, ನಂತರ Settings.

ಡಿಸ್‌ಪ್ಲೇ ಸೆಟ್ಟಿಂಗ್‌ಗಳು

ಸೆಟ್ಟಿಂಗ್ಇದು ಏನು ಮಾಡುತ್ತದೆ
Dark Mode ಡಾರ್ಕ್ ಬ್ಯಾಕ್‌ಗ್ರೌಂಡ್‌ಗೆ ಬದಲಾಗುತ್ತದೆ. ರಾತ್ರಿ ಸಮಯದಲ್ಲಿ ಕಣ್ಣುಗಳಿಗೆ ಆರಾಮದಾಯಕ, ಮತ್ತು ಲೈಟ್ ಸೆನ್ಸಿಟಿವಿಟಿ ಇರುವವರಿಗೆ ಸಾಮಾನ್ಯವಾಗಿ ಹೆಚ್ಚು ಕಂಫರ್ಟ್ ಆಗಿರುತ್ತದೆ.
Font Size Small, Medium ಅಥವಾ Large. Large ಆಯ್ಕೆ ಆಪ್‌ನ ಎಲ್ಲಾ ಕಡೆ ಟೆಕ್ಸ್ಟ್‌ಅನ್ನು ಸುಮಾರು 30% ಹೆಚ್ಚಿಸುತ್ತದೆ.
Default Currency ಎಲ್ಲಾ ಕಡೆ ಬಳಸುವ ಕರೆನ್ಸಿ ಸಿಂಬಲ್‌ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ.
Hide Money on Dashboard ಅಮೌಂಟ್‌ಗಳ ಬದಲು ಚುಕ್ಕೆಗಳನ್ನು ತೋರಿಸುತ್ತದೆ, ಇದರಿಂದ ನಿಮ್ಮ ಸ್ಕ್ರೀನ್ ಅನ್ನು ನೋಡುವ ಯಾರಿಗೂ ಫಿಗರ್ಸ್ ಕಾಣಿಸುವುದಿಲ್ಲ.

ಇವುಗಳನ್ನು ಅನ್ವಯಿಸಲು Save Display Settings ಅನ್ನು ಟ್ಯಾಪ್ ಮಾಡಿ.

ಹಣವನ್ನು ಮರೆಮಾಡುವುದು ಒಂದು ಪ್ರೈವಸಿ ಅನುಕೂಲ ಮಾತ್ರ, ಸೆಕ್ಯುರಿಟಿ ಫೀಚರ್ ಅಲ್ಲ — ಇದು ಅಮೌಂಟ್‌ಗಳನ್ನು ನೋಟದಿಂದ ಮರೆಮಾಡುತ್ತದೆ, ಆದರೆ ಏನನ್ನೂ ಲಾಕ್ ಮಾಡುವುದಿಲ್ಲ. ಅದಕ್ಕಾಗಿ, ಕೆಳಗಿನ App Lock ಬಳಸಿ.

Zebal ಅನ್ನು ಸ್ಕ್ರೀನ್ ರೀಡರ್‌ನೊಂದಿಗೆ ಬಳಸುವುದು

Zebal ಅನ್ನು TalkBack ಜೊತೆ ಕೆಲಸ ಮಾಡುವಂತೆ ರೂಪಿಸಲಾಗಿದೆ. ತಿಳಿದುಕೊಳ್ಳಬೇಕಾದ ಕೆಲವು ವಿಷಯಗಳು:

  • ಪ್ರತಿ ಬಟನ್, ಫೀಲ್ಡ್ ಮತ್ತು ಲಿಸ್ಟ್ ರೋಗೆ ಸರಿಯಾದ ಸ್ಪೋಕನ್ ಲೇಬಲ್ ಇರುತ್ತದೆ, ಮತ್ತು ಟಚ್ ಟಾರ್ಗೆಟ್‌ಗಳು ಕನಿಷ್ಠ 48dp ಇರುತ್ತವೆ, ಆದ್ದರಿಂದ ಅವುಗಳನ್ನು ವಿಶ್ವಾಸಾರ್ಹವಾಗಿ ಆಕ್ಟಿವೇಟ್ ಮಾಡಬಹುದು.
  • ಸಾಮಾನ್ಯವಾಗಿ ಲಾಂಗ್-ಪ್ರೆಸ್ ಮಾಡುವ ಮೂಲಕ ಮಾಡುವ ಆಕ್ಷನ್ ಎಲ್ಲಿ ಇರುತ್ತದೋ — ಗ್ರೂಪ್ ಚಾಟ್‌ನಲ್ಲಿ ಮೆಸೇಜ್ ಆಪ್ಷನ್‌ಗಳು, ರಿಕರಿಂಗ್ ಬಿಲ್ ಅನ್ನು ಪಾಜ್ ಮಾಡುವುದು, ಅಮೌಂಟ್‌ಗಳನ್ನು ಮರೆಮಾಡುವುದು — ಅದೇ ಆಕ್ಷನ್ TalkBack ನ actions menuನಲ್ಲಿ ಕೂಡ ಇರುತ್ತದೆ, ಆದ್ದರಿಂದ ನೀವು ಲಾಂಗ್-ಪ್ರೆಸ್ ಮಾಡುವ ಅಗತ್ಯವೇ ಇಲ್ಲ.
  • ನೀವು ವಾಯ್ಸ್ ಮೂಲಕ ಕೇಳಿದಾಗ Ask AI ನಿಂದ ಬರುವ ಉತ್ತರಗಳು ಆಟೋಮ್ಯಾಟಿಕ್ ಆಗಿ ಗಟ್ಟಿಯಾಗಿ ಓದಿ ಹೇಳಲಾಗುತ್ತದೆ.
  • Font Size ಅನ್ನು Large ಗೆ ಹೆಚ್ಚಿಸುವುದರಿಂದ ಇಡೀ ಇಂಟರ್‌ಫೇಸ್ ದೊಡ್ಡದಾಗುತ್ತದೆ, ಮತ್ತು ಪ್ರತಿ ಸ್ಕ್ರೀನ್ ಟೆಕ್ಸ್ಟ್ ಅನ್ನು ಕತ್ತರಿಸುವ ಬದಲು ಸ್ಕ್ರಾಲ್ ಆಗುತ್ತದೆ.

ಅಕೌಂಟ್

  • Edit Personal Profile & UPI ID — ನಿಮ್ಮ ಹೆಸರು, ಹುಟ್ಟಿದ ದಿನಾಂಕ, ಅಥವಾ ಗ್ರೂಪ್ ಮೆಂಬರ್‌ಗಳು ನಿಮಗೆ ವಾಪಸ್ ಪೇ ಮಾಡಲು ಬಳಸುವ UPI ID ಅನ್ನು ಬದಲಾಯಿಸಿ.
  • Referral code — ನಿಮ್ಮದನ್ನು ಶೇರ್ ಮಾಡಿ, ಫ್ರೆಂಡ್‌ಗೆ ಡಿಸ್ಕೌಂಟ್ ಸಿಗುತ್ತದೆ, ನಿಮಗೆ ಉಚಿತ ಪ್ರೀಮಿಯಂ ದಿನಗಳು ಸಿಗುತ್ತವೆ. ಪ್ರತಿ ಅಕೌಂಟ್ ಒಂದು ರೆಫರಲ್ ಕೋಡ್ ಅನ್ನು, ಒಮ್ಮೆ ಮಾತ್ರ ಬಳಸಬಹುದು.

ಸೆಕ್ಯುರಿಟಿ

App Lock Zebal ಓಪನ್ ಆಗುವ ಮೊದಲು ನಿಮ್ಮ ಫಿಂಗರ್‌ಪ್ರಿಂಟ್, ಫೇಸ್ ಅಥವಾ ಡಿವೈಸ್ PIN ಅನ್ನು ಕೇಳುತ್ತದೆ. ನೀವು ನಿಮ್ಮ ಫೋನ್ ಅನ್ನು ಬೇರೆಯವರೊಂದಿಗೆ ಶೇರ್ ಮಾಡಿದರೆ, ಅಥವಾ ಅದು ಎಂದಾದರೂ ನಿಮ್ಮ ಕೈಯಿಂದ ಹೊರಗೆ ಹೋದರೆ, ಇದನ್ನು ಆನ್ ಮಾಡುವುದು ಒಳ್ಳೆಯದು.

ಬ್ಯಾಕಪ್ ಮತ್ತು ರೀಸ್ಟೋರ್

ಬ್ಯಾಕಪ್ ಅನ್ನು ಆನ್ ಮಾಡಿ. ಅದು ಇಲ್ಲದಿದ್ದರೆ, ನಿಮ್ಮ ಖರ್ಚುಗಳು ಈ ಫೋನ್‌ನಲ್ಲಿ ಮಾತ್ರ ಇರುತ್ತವೆ. ಫೋನ್ ಕಳೆದುಹೋದರೆ ಅಥವಾ ಆಪ್ ಅನ್ನು ಮತ್ತೆ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿದರೆ ಅವು ಹೋಗುತ್ತವೆ.

Auto Online Backup

ಇದನ್ನು ಆನ್ ಮಾಡಿದರೆ, ನಿಮ್ಮ ಖರ್ಚುಗಳು ಮತ್ತು ಬಜೆಟ್ ಹಿಸ್ಟರಿ ಬದಲಾದ ಪ್ರತಿ ಬಾರಿಯೂ ನಿಮ್ಮ ಅಕೌಂಟ್‌ಗೆ ಕಾಪಿ ಆಗುತ್ತವೆ. ಇದನ್ನು ಆನ್ ಮಾಡುವುದೇ ತಕ್ಷಣ ಬ್ಯಾಕಪ್ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ, ಆದ್ದರಿಂದ ನಿಮ್ಮ ಮುಂದಿನ ಖರ್ಚಿಗಾಗಿ ಕಾಯುವ ಅಗತ್ಯ ಇಲ್ಲ.

Restore Data from Cloud

ಹೊಸ ಫೋನ್‌ನಲ್ಲಿ, ಅದೇ ಅಕೌಂಟ್‌ನೊಂದಿಗೆ ಸೈನ್ ಇನ್ ಮಾಡಿ Restore Data from Cloud ಬಳಸಿ.

ರೀಸ್ಟೋರ್ ಮಾಡುವುದರಿಂದ ಈಗ ಫೋನ್‌ನಲ್ಲಿ ಇರುವುದು ನಿಮ್ಮ ಕೊನೆಯ ಬ್ಯಾಕಪ್‌ನೊಂದಿಗೆ ಬದಲಾಗುತ್ತದೆ, ಆದ್ದರಿಂದ ಆಪ್ ಮೊದಲು ಕನ್ಫರ್ಮ್ ಮಾಡಲು ಕೇಳುತ್ತದೆ. ಆ ಬ್ಯಾಕಪ್ ನಂತರ ಸೇರಿಸಿದ್ದು, ಬ್ಯಾಕಪ್ ಆಗದೇ ಇರುವುದು ಏನೇ ಇದ್ದರೂ ಹೋಗುತ್ತದೆ.

ನಿಮ್ಮ ಸ್ವಂತ ಕಾಪಿಯನ್ನು ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡುವುದು

ಮೆನುವಿನಿಂದ, Export Data ನಿಮಗೆ ಎರಡು ಆಯ್ಕೆಗಳನ್ನು ಕೊಡುತ್ತದೆ:

  • CSV — Excel ಅಥವಾ Google Sheets ನಲ್ಲಿ ಓಪನ್ ಆಗುತ್ತದೆ.
  • TXT — ಸರಳವಾಗಿ ಓದಬಹುದಾದ ರಿಪೋರ್ಟ್.

ಎರಡರಲ್ಲೂ ಪ್ರತಿ ಖರ್ಚು ಮತ್ತು ನಿಮ್ಮ ತಿಂಗಳ ಬಜೆಟ್ ಹಿಸ್ಟರಿ ಇರುತ್ತದೆ. ಬ್ಯಾಕಪ್ ಆನ್ ಇದೆಯೋ ಇಲ್ಲವೋ ಎಂಬುದರ ಹೊರತಾಗಿಯೂ ಆಗಾಗ ಇದನ್ನು ಮಾಡುವುದು ಒಳ್ಳೆಯದು — ಇದು ನಿಮ್ಮ ಡೇಟಾ, ಮತ್ತು ನಿಮ್ಮ ಸ್ವಂತ ಕಾಪಿಯನ್ನು ಇಟ್ಟುಕೊಳ್ಳಲು ಯಾವ ಖರ್ಚೂ ಇಲ್ಲ.

Import Data ಒಂದು CSV ಅನ್ನು ಮತ್ತೆ ಓದುತ್ತದೆ.

ನೋಟಿಫಿಕೇಶನ್ ಟೋನ್‌ಗಳು

Notification Preferences ಅಡಿಯಲ್ಲಿ ನೀವು ಪ್ರತಿ ರೀತಿಯ ಅಲರ್ಟ್‌ಗೆ ಬೇರೆ ಬೇರೆ ಸೌಂಡ್ ಸೆಟ್ ಮಾಡಬಹುದು — ಗ್ರೂಪ್ ಮೆಸೇಜ್‌ಗಳು, ಗ್ರೂಪ್ ಖರ್ಚುಗಳು, ಬಜೆಟ್ ವಾರ್ನಿಂಗ್‌ಗಳು ಮತ್ತು ರಿಮೈಂಡರ್‌ಗಳು. ಸ್ಕ್ರೀನ್ ನೋಡದೆಯೇ ಅವುಗಳನ್ನು ಬೇರ್ಪಡಿಸಿ ಗುರುತಿಸಲು ಇದು ಉಪಯುಕ್ತವಾಗಿದೆ.

ನಿಮ್ಮ ಅಕೌಂಟ್ ಅನ್ನು ಡಿಲೀಟ್ ಮಾಡುವುದು

Delete My Account Permanently ನಿಮ್ಮ ಅಕೌಂಟ್, ನಿಮ್ಮ ಪ್ರೊಫೈಲ್ ಮತ್ತು ನಿಮ್ಮ ಆನ್‌ಲೈನ್ ಬ್ಯಾಕಪ್ ಅನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ. ಇದನ್ನು ಹಿಂತಿರುಗಿಸಲು ಆಗುವುದಿಲ್ಲ.

ನೀವು ಈ ಫೋನ್ ಅನ್ನು ಮಾತ್ರ ಕ್ಲಿಯರ್ ಮಾಡಿ, ನಿಮ್ಮ ಅಕೌಂಟ್ ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳಬೇಕೆಂದರೆ, ಅದರ ಬದಲು Erase All Local App Data ಬಳಸಿ.

ಕಾಪಿಯನ್ನು ಇಟ್ಟುಕೊಳ್ಳಬೇಕೆಂದರೆ ಮೊದಲು ನಿಮ್ಮ ಡೇಟಾವನ್ನು ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಮಾಡಿ.
