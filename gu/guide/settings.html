સેટિંગ્સ, બેકઅપ અને એક્સેસિબિલિટી

એપ તમારી જરૂરિયાત મુજબ કામ કરે એ રીતે સેટ કરવું — અને તમારો ડેટા સુરક્ષિત રાખવો.

અહીં જે કંઈ છે એ બધું ઉપર જમણી બાજુના menu (three dots)-માં મળશે, પછી Settings.

ડિસ્પ્લે

સેટિંગએ શું કરે છે
Dark Mode ડાર્ક બેકગ્રાઉન્ડમાં બદલાય છે. રાત્રે આંખો માટે આરામદાયક, અને લાઇટ સેન્સિટિવિટી હોય તેમના માટે પણ ઘણું કમ્ફર્ટેબલ.
Font Size Small, Medium અથવા Large. Large પસંદ કરવાથી આખી એપમાં ટેક્સ્ટ લગભગ 30% મોટું થઈ જાય છે.
Default Currency બધે વપરાતું કરન્સી સિમ્બોલ બદલી નાખે છે.
Hide Money on Dashboard રકમની જગ્યાએ ડોટ્સ બતાવે છે, જેથી તમારી સ્ક્રીન પર કોઈની નજર પડે તો પણ આંકડા દેખાય નહીં.

આ સેટિંગ્સ લાગુ કરવા માટે Save Display Settings પર ટેપ કરો.

પૈસા છુપાવવા એ ફક્ત એક પ્રાઇવસી સુવિધા છે, સિક્યુરિટી ફીચર નથી — આ રકમોને નજરથી છુપાવે છે, પણ કંઈ લોક નથી કરતું. એના માટે નીચે આપેલું App Lock વાપરો.

સ્ક્રીન રીડર સાથે Zebal વાપરવું

Zebal એવી રીતે બનાવવામાં આવ્યું છે કે એ TalkBack સાથે કામ કરે. કેટલીક બાબતો જાણવા જેવી છે:

  • દરેક બટન, ફિલ્ડ અને લિસ્ટ રો ને યોગ્ય સ્પોકન લેબલ છે, અને ટચ ટાર્ગેટ ઓછામાં ઓછા 48dp રાખવામાં આવ્યા છે, જેથી એ ભરોસાપાત્ર રીતે એક્ટિવેટ થઈ શકે.
  • જ્યાં સામાન્ય રીતે લોંગ-પ્રેસ કરીને કોઈ એક્શન કરવાનું હોય — ગ્રુપ ચેટમાં મેસેજ ઓપ્શન્સ, રિકરિંગ બિલ પોઝ કરવું, રકમ છુપાવવી — એ જ એક્શન TalkBack ના actions menu-માં પણ મળે છે, એટલે લોંગ-પ્રેસ કરવાની જરૂર જ નથી પડતી.
  • તમે વોઇસથી પૂછો ત્યારે Ask AI ના જવાબ આપોઆપ મોટેથી વાંચી સંભળાવવામાં આવે છે.
  • Font Size વધારીને Large કરવાથી આખું ઇન્ટરફેસ મોટું થાય છે, અને દરેક સ્ક્રીન ટેક્સ્ટ કાપી નાખવાને બદલે સ્ક્રોલ થાય છે.

એકાઉન્ટ

  • Edit Personal Profile & UPI ID — તમારું નામ, જન્મતારીખ, અથવા ગ્રુપ મેમ્બર્સ તમને પૈસા પાછા ચૂકવવા માટે જે UPI ID વાપરે છે, એ બદલો.
  • Referral code — તમારો કોડ શેર કરો, મિત્રને ડિસ્કાઉન્ટ મળશે, અને તમને ફ્રી પ્રીમિયમ દિવસો મળશે. દરેક એકાઉન્ટ એક રેફરલ કોડ, ફક્ત એક જ વાર વાપરી શકે છે.

સિક્યુરિટી

App Lock ચાલુ હોય તો Zebal ખૂલે એ પહેલાં તમારું ફિંગરપ્રિન્ટ, ફેસ અથવા ડિવાઇસ PIN માંગવામાં આવે છે. તમારો ફોન બીજા કોઈ સાથે શેર થતો હોય, અથવા ક્યારેક હાથમાંથી નીકળી જવાની શક્યતા હોય, તો આ ઓન રાખવું સારું.

બેકઅપ અને રિસ્ટોર

બેકઅપ ચાલુ કરો. આ કર્યા વગર, તમારા ખર્ચા ફક્ત આ ફોનમાં જ રહે છે. ફોન ખોવાઈ જાય કે એપ ફરી ઇન્સ્ટોલ કરો તો એ બધું જતું રહેશે.

Auto Online Backup

આ ચાલુ કરવાથી તમારા ખર્ચા અને બજેટ હિસ્ટ્રી બદલાય કે તરત જ તમારા એકાઉન્ટમાં કોપી થઈ જાય છે. ચાલુ કરતાં જ તરત બેકઅપ લેવાઈ જાય છે, એટલે તમારે આગલા ખર્ચ માટે રાહ જોવાની જરૂર નથી.

Restore Data from Cloud

નવા ફોનમાં, એ જ એકાઉન્ટથી સાઇન ઇન કરીને Restore Data from Cloud વાપરો.

રિસ્ટોર કરવાથી ફોનમાં હાલમાં જે છે એ તમારા છેલ્લા બેકઅપથી બદલાઈ જાય છે, એટલે એપ પહેલાં કન્ફર્મ કરવાનું કહે છે. એ બેકઅપ પછી જે કંઈ ઉમેરાયું હોય પણ બેકઅપ ન થયું હોય, એ ગુમ થઈ જશે.

તમારી પોતાની કોપી એક્સપોર્ટ કરવી

મેનુમાંથી, Export Data તમને બે ઓપ્શન આપે છે:

  • CSV — Excel કે Google Sheets માં ખૂલે છે.
  • TXT — સાદો, વાંચી શકાય એવો રિપોર્ટ.

બંનેમાં દરેક ખર્ચ અને તમારી માસિક બજેટ હિસ્ટ્રી શામેલ હોય છે. બેકઅપ ચાલુ છે કે નહીં એના પર આધાર રાખ્યા વગર, ક્યારેક-ક્યારેક આ કરવું સારું — આ તમારો ડેટા છે, અને પોતાની કોપી રાખવામાં કંઈ ખર્ચ થતો નથી.

Import Data એક CSV પાછું વાંચી લે છે.

નોટિફિકેશન ટોન

Notification Preferences હેઠળ તમે દરેક પ્રકારના એલર્ટ માટે અલગ સાઉન્ડ સેટ કરી શકો છો — ગ્રુપ મેસેજ, ગ્રુપ ખર્ચ, બજેટ વોર્નિંગ અને રિમાઇન્ડર. સ્ક્રીન સામે જોયા વગર પણ એ ઓળખવા માટે આ ઉપયોગી છે.

તમારું એકાઉન્ટ ડિલીટ કરવું

Delete My Account Permanently તમારું એકાઉન્ટ, તમારી પ્રોફાઇલ અને તમારો ઓનલાઇન બેકઅપ કાઢી નાખે છે. આ પાછું લાવી શકાતું નથી.

જો તમારે ફક્ત આ ફોન ક્લિયર કરવો હોય પણ એકાઉન્ટ રાખવું હોય, તો એની જગ્યાએ Erase All Local App Data વાપરો.

કોપી રાખવી હોય તો પહેલાં તમારો ડેટા એક્સપોર્ટ કરી લો.
